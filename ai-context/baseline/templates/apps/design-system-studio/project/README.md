# Project Design System

Эта директория принадлежит проекту. Она использует неизменяемую library из
`ai-context/baseline/apps/design-system-studio/` и сохраняет семь разделов:

1. `base-system/`
2. `tokens/`
3. `components/`
4. `layouts/`
5. `screens/`
6. `flows/`
7. `mockups/`

`studio.json` хранит устойчивые ids и связи между разделами. Исходный код,
тесты, примеры и документация конкретного проекта находятся в соответствующих
директориях рядом с ним.
