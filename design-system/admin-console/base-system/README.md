# Base System

- Платформа: responsive Web / React.
- Library contract: AIC Design System Studio reference renderer.
- Переопределено: brand palette, admin navigation, dense tables и responsive
  sidebar/bottom navigation.

При обновлении основы проверить focus states, touch targets, формы, таблицы и
обе адаптивные раскладки.
